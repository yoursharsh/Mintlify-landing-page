# Mintlify Documentation Website

A desktop-first recreation of the Mintlify documentation platform website using only HTML and CSS.

## 📌 Project Overview

This project recreates the structure, layout, typography, colors, spacing, and visual style of the Mintlify website based on the provided reference.

The main focus of the project is to practice:

- HTML page structure
- CSS layouts
- Grid and Flexbox
- Typography
- Spacing and alignment
- Dark UI design
- Cards and sections
- Image positioning
- Footer and navigation layouts

## 🛠️ Technologies Used

- HTML5
- CSS3

No JavaScript, Tailwind CSS, or other frameworks were used.
